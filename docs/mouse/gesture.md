# 鼠标手势

按住鼠标右键拖动，画出方向，松开就执行。在所有软件里都能用。

## 常用手势

| 手势（按住右键划） | 作用 |
|---|---|
| ← / → | 后退 / 前进 |
| ↑↓ | 刷新网页 |
| ↓→ | 关闭标签页 |
| ←↑ | 恢复刚关的标签页 |
| ↓← | 最小化窗口 |

还有回到顶部、切换标签页等，都能在“鼠标手势”页里修改。

## 在音乐和视频播放器里

同样的手势在播放器里自动换成播放控制：← / → 上一首 / 下一首，↑ / ↓ 音量加 / 减，↓↑ 播放 / 暂停。
支持网易云音乐、QQ 音乐、酷狗、酷我、汽水音乐、PotPlayer、QQ 影音、迅雷影音、VLC 等。

## 选项

- **显示轨迹和提示**：画的时候显示轨迹和还能画出的手势。
- **停住不动就取消**：画的过程中停住超过设定时间就取消；任何时候按 `Esc` 也能取消。
