# 安装与开始使用

超级快捷键是一款开箱即用的 Windows 效率工具，用快捷键、鼠标手势、屏幕边缘等方式，让常用操作一步完成。
支持 64 位的 Windows 10（1809 或更新）和 Windows 11。

## 下载安装

到 [下载](/download) 页下载安装版或免安装版：

- **安装版**：双击安装，不需要管理员权限。
- **免安装版**：解压后得到一个 `SuperKey` 文件夹，双击里面的 `SuperKey.Core.exe`。

## 第一次运行

1. 运行后，程序常驻在屏幕右下角的托盘里（闪电图标），左键点它打开主窗口。
2. 装好就能用：鼠标手势、短语替换、CapsLock 增强等都已经带了常用的规则，先在 [概览](/start/overview) 里看看都有什么。
3. 在主窗口里打开、关闭各个功能，修改规则；改动会立即保存并生效。

## 各个功能

| 功能 | 一句话 |
|---|---|
| [短语替换](/keyboard/phrase) | 打几个字母，出来一整段 |
| [多步热键](/keyboard/hotkey) | 一个快捷键打开网站、软件，或者连着做好几件事 |
| [CapsLock 增强](/keyboard/capslock) | 按住 CapsLock，字母键变成方向、翻页、删除 |
| [复制搜索](/keyboard/copy-search) | 选中文字，连按两次 Ctrl+C，再按一个键就搜 |
| [鼠标手势](/mouse/gesture) | 按住右键划一下：后退、刷新、关标签页 |
| [鼠标按键](/mouse/buttons) | 侧键、右键加滚轮也能执行动作 |
| [屏幕边缘](/mouse/edge) | 鼠标放到屏幕边上滚一下：调音量、调亮度 |
| [程序与方案](/manage/apps) | 给某个软件单独设置；为一类软件准备好的方案 |
| [全部规则](/manage/rules) | 所有规则都在这里，看哪些在生效 |
| [设置](/manage/settings) | 外观、暂停与禁用、同步、诊断 |
