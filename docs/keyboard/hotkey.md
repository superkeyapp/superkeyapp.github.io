# 多步热键

按下一个组合键，执行设置好的动作：打开网站、打开软件、按键、打字、窗口操作……一个快捷键也可以按顺序做好几件事。
也可以连续按几个组合键（如 `Ctrl+K`, `Ctrl+F`），快捷键不够用时很方便。

## 自带的快捷键

| 快捷键 | 作用 |
|---|---|
| `Ctrl+Alt+Shift+P` | 暂停 / 恢复所有功能 |
| `Ctrl+Alt+Shift+F` | 在全屏程序（游戏、全屏视频）里临时启用 / 暂停 |

## 例子

- `Ctrl+Alt+B` → 打开百度
- `Ctrl+Alt+X` → 打开微信
- “老板键”`Ctrl+Alt+H` → 静音，再显示桌面

在“多步热键”页点“添加”，按下组合键，再添加要做的动作。“更多选项”里可以设置只在某些软件里生效。
