# 短语替换

输入一个缩写，自动替换成设置好的内容。邮箱、地址、常用回复，设一次，在哪个软件里打字都能用。

## 自带的短语

| 输入 | 变成 |
|---|---|
| `,,d` | 今天的日期，如 2026-10-20 |
| `,,t` | 日期和时间，如 2026-10-20 14:30:05 |
| `,,sj` | 现在的时间，如 14:30:05 |
| `,,rq` | 中文日期，如 2026年10月20日 |
| `,,xq` | 星期几，如 星期二 |

## 自己添加

在“短语替换”页点“添加”，填上缩写和要替换成的内容。缩写建议用 `,,` 开头，平时打字不会误触发。
